## What this baseline does not establish

Review spans the full recording, but annotations are not an exhaustive transcription of every frame or every visible field. Source-a has five source-reference residual fields; source-b has 14 before its two source amount corrections, with 12 remaining attribution limits; source-c has five anchor intervals with unlabeled intervening causes. The individual values are preserved in the gap register and local balance artifacts. Matching report totals does not independently label those causes or rule out offsetting errors.

The reference includes observations derived from before/after state changes, explicitly marked as such. Those observations can test consistency but cannot independently prove causal attribution. No overall recognition accuracy or prediction precision is claimed; unreviewed prediction queues are not false-positive counts. The exact-frame, accepted-checkpoint and consumer-opening measures answer different questions.

Absolute energy, continuous hidden conditions, complete inventory, exhaustive narrative/event titles, all account/item rewards, all turn-boundary timings and native-frame event recall remain ungraded or unobservable as specified in the section scorecards. Optional UI panels and pauses are not assumed requirements of future users.

## Reproduce and inspect

Run from the repository root with the existing Python environment and preserved local artifacts:

```powershell
.venv/Scripts/python.exe analyzer/lab/reproduce_baseline.py
.venv/Scripts/python.exe analyzer/lab/audit_baseline_deliverables.py
```

The first command verifies the original video, source seals, frozen analyzer/report, evaluator commands and unchanged metric tables. It writes `.local/full-run-baseline-v1/reproduction-audit.json` and per-command logs. The second checks document links, linked source-image hashes, score-input hashes and occurrence uniqueness, writing `deliverables-audit.json`. Both commands supplement the semantic review documented above; neither performs fresh visual review or certifies exhaustive recall.

The detailed references, screenshot manifests, amendments, frozen report and section-specific evaluators are preserved under `.local/full-run-baseline-v1/`; gameplay images are under `.local/full-recording/v1/gameplay/`. They are intentionally ignored by Git. The public documents and scripts alone are insufficient to reproduce the numeric results from a fresh clone: preserve these local directories and the original video. Reproduction here means rerunning the evaluation on those preserved artifacts, not rerunning whole-video OCR or claiming independent annotation.
